# 现有网站对照 V1.0

结论：这是一个可演示的模板，不是具备真实交易能力的最小商业版本。公开页已标明测试模板。

| 要求 | 现状 | 是否达到 |
| --- | --- | --- |
| 首页、分类、商品详情、SKU、购物车 | 有。分类可筛选，商品页有变体和库存 | 部分达到 |
| 站内搜索 | 商店支持关键词、宠物、分类、排序 | 部分达到 |
| 结账支付 | 结账只记一笔演示订单，不向支付机构扣款 | 未达到 |
| 订单查询 | 顾客可凭登录或订单令牌查看自己的订单 | 部分达到 |
| 联系、退款、配送政策 | 有关于、隐私、退款页；不承诺发货日期 | 部分达到 |
| 移动端 | 页面按窄屏排过 | 部分达到 |
| SEO 与商品结构化数据 | 有标题、站点地图；商品页有 Product JSON-LD | 部分达到 |
| 顾客不能改价格和库存 | 前台没有这些写入入口；写入在服务端按角色检查 | 达到 |
| 独立后台与登录 | 有商家入口，店主、管理员、店员角色不同 | 部分达到 |
| 商品、分类、图片、库存、订单、发货、退款 | 后台有对应页面；图片是站内地址，不是安全上传管线 | 部分达到 |
| 客服 | 只有支持邮箱，没有工单 | 未达到 |
| 销售与毛利 | 店主可见；口径见 PRD。管理员和店员看不到成本和库存 | 部分达到 |
| 审计日志 | 没有独立审计表 | 未达到 |
| 内容管理 | 店主可改公告和首页文案 | 部分达到 |
| HTTPS | Vercel 默认 HTTPS | 达到 |
| WAF / DDoS | 免费套餐只有一条登录限流。没有 Cloudflare，也没有付费 WAF | 未达到 |
| 接口限流 | 程序内按地址限流，冷启动会清零 | 部分达到 |
| 管理员 MFA | 只有邮箱和密码 | 未达到 |
| RBAC | 服务端有角色检查，不是只藏按钮 | 部分达到 |
| PostgreSQL / Supabase | 代码可接 `DATABASE_URL`。线上 mu 没用，仍是函数里的临时库 | 未达到 |
| 真实支付与 Webhook 签名 | 没有 | 未达到 |
| 备份与恢复演练 | 没有 | 未达到 |
| 依赖漏洞扫描、三套环境隔离 | 没有独立预发布环境，也没有扫描门禁 | 未达到 |
| Next.js | 现用 TanStack Start + Nitro，不是 Next.js | 选型不同，见架构 |

技术栈不按文档改成 Next.js，除非审查时明确要求重写。现有栈已经在 Vercel 上跑通。
